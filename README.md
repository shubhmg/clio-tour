# Clio in Glass

A complete UI tour of [Clio](https://clio.natrajplastic.in) — a quantity-only purchasing ERP
for a laminates importer — in its `glass` design language.

**→ https://shubhmg.github.io/clio-tour/**

28 screens across 6 chapters, each in desktop and phone, light and dark (112 captures).
Screens that only exist after an interaction — action sheets, the SKU story, the catalog
drill-down, planning settings — are driven to that state before the shot.

Captured with Playwright against the live seeded demo (41 months of purchase and sale
history) at 1440×900 @2x and 390×844 @3x with a real iOS user-agent, so the phone shots
show the floating glass dock rather than a squeezed desktop layout.
